# SWE Prep 1.0.0

The first stable version of SWE Prep brings local C++ interview practice, focused technical interviews and full system-design practice together in a bilingual desktop application.

## A quieter reading experience

- Refined question cards with a consistent native Chinese/English reading font, compact 15 px body text, balanced line lengths and more comfortable spacing.
- Clearer title hierarchy and Markdown headings, restrained surfaces and borders, and a simpler interview header. The violet accent remains focused on selection and primary actions.
- Readable code blocks and tables, keyboard focus indicators, light/dark themes and responsive layouts are preserved.

## Interview practice

- All 100 LeetCode Hot 100 problems support real local C++20 judging in Function and ACM modes, with sourced complexity expectations and enforced local time, memory and output limits.
- Technical Deep Dive offers 180 bilingual foundation, scenario and troubleshooting topics, streamed interviews, optional reference answers and evidence-based five-dimension feedback.
- System Design includes 26 bilingual scenarios, five practice stages, capacity and architectural trade-offs, Markdown/Mermaid notes and eight-dimension feedback.
- Optional voice transcription uses a separate OpenAI key and explicit audio submission. Interview generation continues to use Claude or DeepSeek.
- Local history, exports, optional timers, spaced review and provider-reported usage accounting remain available. Credentials are stored in the runtime application-config directory, outside the app bundle; no keys are included in downloads.

## Reliability and updates

This release includes the preview.5/preview.6 judge, editor, settings and interview fixes, including failed-draft retries, recoverable timer loading, current Review counts, stable session language, bounded model retries, atomic judge persistence and serialized key saves. See the earlier version notes and [bug-fix report](../BUGFIXES_2026-10-17.md) for details.

Stable GitHub releases are marked as Latest rather than prereleases. Signed updates retain the existing compatibility endpoint, so updater-enabled previews can upgrade to 1.0.0. Once that feed reaches a stable version, later previews do not replace it. Updates still require confirmation before installation and restart and preserve local data.

## Installation and limits

- macOS 13 or later on Apple Silicon (arm64). LeetCode judging requires a local C++20 compiler, such as Xcode Command Line Tools.
- The app is ad-hoc signed and **not Apple-notarized**. Version 1.0 does not imply Apple notarization or Windows/Intel support. Run the installed app outside its mounted DMG.
- Existing updater-enabled previews can upgrade through Settings after feed publication. Preview.1 and first-time users need the DMG or app ZIP once. Back up local application data before upgrading.
- The software remains proprietary and available for personal, non-commercial evaluation under the bundled license. AI output can be incorrect; provider availability and billing remain the provider's responsibility. Cost records are estimates, with unknown amounts preserved.
- Final regression is offline and does not make new paid interview or voice requests. Historical live-provider results and their recorded limitations remain unchanged.
