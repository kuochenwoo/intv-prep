# SWE Prep 0.1.0-preview.5

This macOS 13+ Apple Silicon preview fixes bugs found in a full review of the judge, editor, System Design and Settings, and makes the missing-API-key warning compact.

- LeetCode: opening a problem from Review while a run is in progress no longer overwrites the previous problem's saved solution. The new problem opens after the run finishes, and only your own typing saves drafts.
- LeetCode: after "Clear solution" or "Clear all", reopening a problem shows its template instead of the deleted code, so the editor and the judged code always match.
- Judge: integer answers must now match exactly. An int overflow on Min Stack or an off-by-one median is no longer accepted. Decimal answers use an absolute 1e-5 tolerance, as on LeetCode.
- Judge: a passed hidden test stores only its summary, and failing cases keep a 4 KB excerpt. Earlier results are shrunk once on launch, so a fully solved library no longer stores and loads about 21 MB per mode.
- System Design: opening a weak point from Review while a request or voice input is running waits for it to finish, so the old request can no longer pull the screen back or stream into the new session.
- System Design: the live feedback stream shows the actual gap instead of repeating the interviewer's question.
- System Design: AI-assisted answers are no longer graded as your own. With no independent answer, every dimension is unassessed, and "Stages discussed" lists only stages you answered yourself.
- Settings: saving the compiler no longer discards an unsaved API key or provider change.
- A successful model response is kept even when the local usage record cannot be written, so Retry does not pay twice.
- The "API key is missing or empty" warning is now a compact pill in Deep Dive, System Design and Settings.

Existing installations with the updater can discover this version after feed publication. First installs and preview.1 users need the DMG or app ZIP once. Run the app outside its mounted DMG. This is an ad-hoc signed preview, not Apple-notarized; macOS 13+ arm64 remains the supported target.

History and provider-specific `.env` credentials remain outside the application bundle. Back up runtime application data before upgrading. No paid model/transcription calls are part of this release validation. See `docs/UPDATES.md` and `docs/AUTOMATIC_RELEASES.md`.
