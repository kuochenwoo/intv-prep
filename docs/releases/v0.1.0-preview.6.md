# SWE Prep 0.1.0-preview.6

This macOS 13+ Apple Silicon preview addresses the low-priority findings from the October 16 bug review, improving draft recovery, timers, Review freshness and interview request handling.

- **LeetCode drafts:** failed saves show an unsaved status and a Retry action. Retrying preserves the original problem, mode and text even after navigation; clearing solutions clears the corresponding failed-save entries.
- **Review:** the navigation count refreshes after judge/interview changes, at local midnight and when the app regains focus or visibility. Older reloads cannot overwrite newer results. New System Design feedback uses its completion time, so dismissing a weakness does not hide later feedback from a session that was already open.
- **Timers:** LeetCode and interview timers offer Retry when their initial load fails. Switching sessions clears the previous clock before loading the next one.
- **System Design:** Finish requires at least one submitted answer before requesting feedback. Newly generated reference answers respect the 6000-character submission limit; older saved references up to 12000 characters remain explicitly submittable as AI-assisted answers without raising the limit for human drafts.
- **Technical Deep Dive:** session restoration preserves the default Core topic filter. New questions save their language, and subsequent answers, follow-ups, references, retries and feedback keep that language when the UI language changes. Older cached questions remain readable, with language inferred from their opening when metadata is absent.
- **Connection and error messages:** Generate names the configured provider, while saved-session actions name that session's provider. A failed Deep Dive request no longer leaves the badge at Requesting after navigation. Shared errors remove the generic JavaScript Error prefix and translate invalid Review item errors in English mode.
- **AI requests:** custom Claude feedback and repair prompts describe the same schema the provider enforces. Refusals, output-limit terminations and incomplete streams require manual retry instead of repeating identical requests automatically. Normally completed responses with malformed content retain bounded format retries. SSE streams preserve their final data line even without a trailing newline.
- **Local storage and judging:** simultaneous voice/interview key saves cannot overwrite each other. Judge results and Review logs commit in one transaction. The generated C++ wrapper correctly reads a string following an empty flat array.
- **Repository hygiene:** nine unreferenced raw calibration logs/transcripts are untracked and ignored, retaining local copies. Referenced failure evidence and JSON/JSONL acceptance reports remain tracked. Local bug-review notes and compiler/interpreter caches are ignored too.

The fixes passed 128 offline Rust tests, including real compilation and judging of all 100 LC references in both modes, and 16 frontend tests. Frontend build, native compile and TypeScript checks passed. No paid model or voice requests were made. These checks do not constitute live-provider acceptance or interactive UI acceptance; preview.6 packaging and installation acceptance remain separate. See [the fix report](../BUGFIXES_2026-10-17.md).

Existing updater-enabled installations can discover this version after publication and update-feed advancement. First installs and preview.1 users need the DMG or app ZIP once. Run the app outside its mounted DMG. This is an ad-hoc signed preview, not Apple-notarized; macOS 13+ arm64 remains the supported target.

History and provider-specific `.env` credentials remain outside the app bundle, with no automatic key migration. Back up runtime application data before upgrading. See [signed updates](../UPDATES.md) and [automatic releases](../AUTOMATIC_RELEASES.md).
