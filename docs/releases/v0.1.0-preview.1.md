# SWE Interview Prep 0.1.0-preview.1

A macOS Apple Silicon preview for personal interview practice. Proprietary preview;
all rights reserved, with personal non-commercial evaluation permitted by LICENSE.

- 100 LeetCode Hot 100 problems with real C++20 Function/ACM judging, sourced complexity requirements and local resource limits.
- 180 bilingual P1 technical topics and 26 P2 system-design scenarios.
- Claude/DeepSeek streaming interviews, references, follow-ups and evidence-based feedback.
- Saved drafts/history, Review statistics, optional timers, confirmed exports and API usage records.
- Optional OpenAI gpt-4o-mini-transcribe voice input; its key is separate and never used for interview generation.

## Install and configure

Target: macOS 13 or newer on Apple Silicon (arm64). Intel, Linux and Windows are not
part of this preview. Open the DMG and drag the app to Applications, or extract the
app ZIP. No Node.js, Rust or source checkout is required to use the installed app.
LeetCode judging additionally needs a local C++20 compiler; install Apple's Command
Line Tools with `xcode-select --install` if none is available, then detect it in Settings.

The preview is ad-hoc signed, not Apple-notarized. macOS may require an explicit
Open Anyway action under Privacy & Security for an intentionally downloaded app.
No instructions to disable Gatekeeper or clear quarantine are required.

Configure your own Claude/DeepSeek keys in Settings. Installed Release builds keep
keys in the application-config directory's `.env` (0600), whose exact path is shown
in Settings. Development builds retain the ignored checkout `.env`. No keys are
bundled or automatically migrated; no credentials are written to SQLite. On macOS,
the standard config/data directory is `~/Library/Application Support/local.swe.interview-prep/`.

Before upgrading, quit the app and back up that directory. Replacing the app bundle
preserves this directory; do not delete it to upgrade. Keep `.env` out of shared backups.
Reinstalling the previous binary does not undo database migrations; restore a compatible
backup when rolling back. This preview does not promise downgrade compatibility.

## Known limits

AI output can be wrong. Some P1 mandatory checkpoints still exceed the visible ask;
not every generated output passed manual acceptance. The newest six P2 scenarios
have content/offline/UI coverage, not complete live multi-stage certification.
Judging runs your code as your user and is not an untrusted-code sandbox. Local tests
cannot prove Big-O complexity. Voice requires microphone permission, connectivity and
an OpenAI key; no new paid voice or text batch is part of this release preparation.
Automatic updates, Developer ID notarization and additional platforms are deferred.

The release contains dependency notices and SHA-256 checksums. Only a reviewed draft
should be published; a successful build is not permission to make the release public.
