# SWE Prep 0.1.0-preview.2

This macOS 13+ Apple Silicon preview adds signed in-app updates and API-key status indicators.

- Settings and P1/P2 show warnings for missing/empty keys and green status for locally saved keys. Green does not certify provider authentication.
- Installed Release apps check for updates after startup and every six hours, with a persistent opt-out and manual Check for updates in Settings.
- Available updates show release notes and require confirmation before download, signature verification, installation and restart. Active judging/model/transcription work blocks installation.
- Update archives are signed independently of macOS ad-hoc code signing. Both the payload and its announced version must match the signature. Local history, drafts and provider `.env` files live outside the replaced app bundle.

Install this version manually from the DMG/ZIP if you have preview.1: that older binary did not contain an updater. Move the app out of the mounted DMG before launching it. The preview remains ad-hoc signed and not Apple-notarized; see the preview.1 installation/backup guidance and `docs/UPDATES.md`.

The update feed includes only deliberately published previews. Drafts and failed builds are excluded. Until a preview with signed updater artifacts is published, the app reports that the feed could not be checked rather than claiming it is current. Subsequent published previews can be installed from this version's update UI.

AI output and local judging retain the limitations recorded in preview.1. No paid model or voice calls are part of this updater change. Intel and other operating systems remain outside this preview.
