# SWE Prep 0.1.0-preview.4

This macOS 13+ Apple Silicon preview fixes system-design scenario navigation and introduces automatic preview publication after reviewed version increases.

- Switching system-design scenarios closes the displayed interview, so an unrelated previous session no longer occupies the new scenario. Persisted interview history remains available, draft-save failures block navigation, and late restoration cannot reopen the previous session.
- A merged PR that increases the prerelease version and supplies versioned notes now releases after successful main CI: create the matching tag, build/sign the application, verify uploaded artifacts, publish the prerelease and advance the signed update feed. Ordinary merges without a version increase do not release.
- Reuse the same signed build for manual tags and automatic releases. Manual tag builds remain drafts. Conflicting tags, downgraded versions, unknown uploaded digests and mismatched commits are refused; retries can repair an already published feed without replacing public artifacts.

Existing installations with the updater can discover this version after feed publication. First installs and preview.1 users need the DMG or app ZIP once. Run the app outside its mounted DMG. This is an ad-hoc signed preview, not Apple-notarized; macOS 13+ arm64 remains the supported target.

History and provider-specific `.env` credentials remain outside the application bundle. Back up runtime application data before upgrading. No paid model/transcription calls are part of this release validation. See `docs/UPDATES.md` and `docs/AUTOMATIC_RELEASES.md`.
