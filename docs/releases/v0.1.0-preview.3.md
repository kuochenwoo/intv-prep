# SWE Prep 0.1.0-preview.3

This macOS 13+ Apple Silicon preview includes signed in-app updates and refines API-key status presentation.

- Keep provider status badges inline with headings and nearby labels, with compact warning banners and consistent alignment in Settings and interview screens.
- Remove the obsolete repository transfer archive; it is not application content.
- Include the signed updater introduced in preview.2: automatic checks at startup and every six hours, persistent opt-out, manual checks, release notes and confirmed download/install/restart.
- Verify updater signatures and signed versions before replacing the app. Active judge/model/transcription work and unsaved drafts block installation. History and provider-specific credential files remain outside the app bundle.

For a first install, or when upgrading from preview.1, download the DMG or app ZIP and install manually. Preview.2 and later can discover this version after publication of the verified update feed. Run the app outside its mounted DMG. The bundle is ad-hoc signed, not Apple-notarized; Intel and other operating systems are outside this preview.

Back up the runtime application-data directory before upgrading. No provider API keys, interview histories or recordings are bundled. Locally saved green API-key status does not certify provider authentication. No paid model or transcription requests are part of release validation. Existing AI and local-judge limitations remain documented in preview.1.

See `docs/UPDATES.md`, `docs/RELEASING.md` and `docs/UPDATER_ACCEPTANCE.md` for update, installation and validation details.
